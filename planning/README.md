# Rekordly v2 Planning Index

This directory contains the single source of truth for Rekordly v2 product and implementation planning.

## Read in this order

1. [`final-v2-plan/`](./final-v2-plan/README.md) — locked product direction, business model, architecture decisions, launch scope and operational gates.
2. [`v2-system-blueprint/`](./v2-system-blueprint/README.md) — implementation-level workflows, rules, APIs, state transitions, page responsibilities and acceptance criteria.
3. [`../AGENT_RULES.md`](../AGENT_RULES.md) — non-negotiable engineering, financial-integrity and security rules.
4. [`../worklog.md`](../worklog.md) — chronological record of completed implementation work and verification.
5. [`../evaluation/`](../evaluation/) — executed evaluation evidence.

Historical competitor research, earlier proposals, one-off delegation prompts and phase handoff files were deliberately removed after their applicable decisions were reconciled into the final plan and system blueprint. New planning must update the relevant authoritative document above rather than recreate parallel plans.
